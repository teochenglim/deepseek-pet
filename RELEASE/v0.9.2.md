# RELEASE v0.9.2: statusline text rows stay aligned in Claude Code

**Status:** active
**Exit gate:** in a real Claude Code session the three text rows start in one column beside the avatar, and `make check` is green
**Depends on:** v0.9.1
**Requirements:** R-X1

Patch: no AC change, no new dependency.


> **Removed in v0.9.5:** the status line (and its install row, avatar and settings writer) is gone; "Show context" now reads the Claude Code transcript instead of numbers recorded by the status line. The acceptance criteria below that described the status line were dropped with it.

## What failed

In Claude Code the text rows beside the avatar drifted (`context` to the right, `$0.00 this session` to the left). `make statusline-preview` in the same terminal was aligned, and the half-block avatar of v0.9.0 was aligned in Claude Code too. The v0.9.1 avatar used all sixteen quadrant glyphs; Claude Code evidently measures some of them differently from the terminal, which shifts the text that follows.

## Fix

The avatar generator (`tools/make_statusline_logo.py`) now draws with only the half blocks and the full block (`▀ ▄ ▌ ▐ █`), the glyphs that lined up in v0.9.0. Each 2 x 2 cell is split top/bottom or left/right (whichever fits better) or drawn flat; edge cells use the glyph that covers the drawn sub-pixels best. Still 16 rows, 24-bit colour; slightly less horizontal detail than the quadrant version. Padding is unchanged (no-break spaces).

New test `ac_0_9_1_avatar_uses_only_widely_measured_block_characters` fails if another block glyph gets into the avatar and checks that the three text rows start in one column.

## Limits

- This is a diagnosis from screenshots, not reproduced: needs a manual look in Claude Code (rebuild, restart the session). If the rows still drift, the next suspect is the padding spaces (no-break spaces), then the glyph set.
- 16 rows is tall: in a short terminal window Claude Code redraws the status line over the footer and fragments show in scrollback. Use a taller window, or `make statusline-logo ROWS=12` and rebuild.
