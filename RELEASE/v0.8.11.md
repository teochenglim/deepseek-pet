# RELEASE v0.8.11: security scan - url 2.5.9

**Status:** active
**Exit gate:** the GitHub Actions security scan (cargo-audit / cargo-deny) passes on `desktop/cross-platform/src-tauri/Cargo.lock`, and `make check` is green
**Depends on:** v0.8.10
**Requirements:** R-D1

Dependency bump only: no AC change, no behaviour change.

## What failed

The security scan flagged `url 2.5.8` in `desktop/cross-platform/src-tauri/Cargo.lock`:

```
error[vulnerability]: Stack overflow in `Url::origin()` on nested `blob:` URLs
```

`url` is a transitive dependency of tauri; the app does not parse untrusted nested `blob:` URLs, but the scan is a gate.

## Fix

`cargo update -p url --precise 2.5.9` in `desktop/cross-platform/src-tauri` (also moves `form_urlencoded` 1.2.2 -> 1.2.3). Only `Cargo.lock` changes.
