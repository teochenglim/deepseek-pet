# Frame provenance

All frames are generated by `tools/convert-assets.py` from `tools/state-map.json` (clips from
`big-blue-fish-desktop-pet/code/BigBlueFish.Windows/assets/fish/`, Apache-2.0), decoded with
`libvpx-vp9` so alpha is kept, cropped to a per-clip shared box, fitted into 192x208. Run `make convert-assets`.

| State | Source clip |
|---|---|
| idle | 待机呼吸休闲.webm (idle/00.png is the original v0.1.0 still source) |
| running | 工作状态-忙碌点按.webm |
| running-left | 原地左转奔跑.webm |
| running-right | 原地左转奔跑.webm, mirrored |
| failed | 工作状态-垂头叹气冒汗.webm |
| waiting | 工作状态-原地踱步张望.webm |
| review | 工作状态-思考冒泡.webm |
| waving | 点击回应-元气挥手.webm |
| jumping | 点击回应-开心跃动.webm |

`pet.json` (one level up) records the exact source, resolution, frame count and unmapped clips.
