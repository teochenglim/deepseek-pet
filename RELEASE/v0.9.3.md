# RELEASE v0.9.3: the avatar and the context display are two separate functions

**Status:** active
**Exit gate:** the avatar and the context rows are built by separate functions, the printed status line is unchanged, and `make check` is green
**Depends on:** v0.9.2
**Requirements:** R-X1

Refactor: no new dependency, no change to what the status line prints (same as `make statusline-preview`).


> **Removed in v0.9.5:** the status line (and its install row, avatar and settings writer) is gone; "Show context" now reads the Claude Code transcript instead of numbers recorded by the status line. The acceptance criteria below that described the status line were dropped with it.

## What

Before, `statusline.rs` built the text rows and the avatar in one `render`. Now:

- `statusline::avatar_lines()` is the avatar alone.
- `context::status_rows(doc)` is the context display alone (model and folder, context bar with tokens, session cost). It lives in `context.rs` beside the "Show context" text, so the numbers are formatted in one module.
- `statusline::compose(avatar, rows)` joins them side by side (centred, padded to one column); `statusline::render` is just `compose(avatar_lines(), status_rows(doc))`.

Either part can now be tested, changed or replaced without the other (for example a stacked layout would only change `compose`).
