# RELEASE v0.8.10: README install, upgrade and repair split

**Status:** active
**Exit gate:** the README gives one command each for first install, upgrade and repair, and `make check` is green
**Depends on:** v0.8.9
**Requirements:** R-D1

Docs-only change: no AC change, no behaviour change.

## What failed

v0.8.9 documented the recovery as three lines (`untap`, `tap`, `install`) in a paragraph after the install block, so first install, upgrade and repair were hard to tell apart and an upgrade looked like it took three commands.

## Fix

README Install is now three labelled cases, one command each:

- **First install:** `brew tap teochenglim/deepseek-pet https://github.com/teochenglim/deepseek-pet && brew install --cask deepseek-pet`
- **Upgrade:** `brew upgrade --cask deepseek-pet` (`brew upgrade` refreshes the tap itself)
- **Repair** (`Cask 'deepseek-pet' is unreadable ... <<<<<<< HEAD`): `brew untap teochenglim/deepseek-pet; brew tap ... && brew install --cask deepseek-pet`

The DMG download stays as the non-Homebrew alternative.
