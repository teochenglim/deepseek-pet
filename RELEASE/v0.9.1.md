# RELEASE v0.9.1: sharper statusline avatar and a way to preview it

**Status:** active
**Exit gate:** the avatar is readable in a real terminal, `make statusline-preview` prints the status line, and `make check` is green
**Depends on:** v0.9.0
**Requirements:** R-X1

Patch on v0.9.0: no AC change, no new dependency, no behaviour change beyond the avatar size.


> **Removed in v0.9.5:** the status line (and its install row, avatar and settings writer) is gone; "Show context" now reads the Claude Code transcript instead of numbers recorded by the status line. The acceptance criteria below that described the status line were dropped with it.

## What

- The avatar was 9 x 12 pixels and looked blurred in Claude Code. It is now drawn with quadrant block characters (2 x 2 sub-pixels per character, best two-colour fit per cell) over 16 rows: about 51 x 32 sub-pixels, roughly seven times the detail of the first version. `make statusline-logo ROWS=20` regenerates it at another size.
- `make statusline-preview` (`scripts/statusline-preview.sh`) builds the app and prints the status line in the terminal with sample numbers, so the final ANSI render can be judged without starting Claude Code. `echo '<payload>' | scripts/statusline-preview.sh -` uses your own payload. It runs against a scratch home, so the real `~/.deepseek-pet/context.json` is untouched.

## Limits

Quadrant blocks are the sharpest a terminal gets without an image protocol (Claude Code's status line does not pass those through); more rows make a taller status line. Two colours per character, so very fine detail is approximated. Needs a manual look in a real Claude Code session.
