# RELEASE v0.9.4: statusline is just the avatar, Show Claude context is its own feature

**Status:** active
**Exit gate:** the status line prints only the avatar, "Show Claude context" is on both menus, the context numbers are still recorded, and `make check` is green
**Depends on:** v0.9.3
**Requirements:** R-X1

No new dependency.

## What

- **Statusline = message of the day.** `deepseek-pet --statusline` now prints only the deepseek avatar: no model, bar or cost beside it. That also removes the side-by-side alignment that drifted in Claude Code (v0.9.1 to v0.9.3). `statusline::compose` and `context::status_rows` are gone.
- **Context = its own feature.** The menu entry is named **Show Claude context** (menu-bar icon and right-click menu). `context.rs` owns saving (`context::save`) and showing (`context::summary` / `load_text`) the numbers; `statusline.rs` only calls `context::save` once per run, silently, because the status line command is the only place Claude Code hands out the context window, tokens and cost. The atomic file write moved to `home::write_atomic`, shared by both.
- The no-data hint now says how to get data: install the statusline, restart Claude Code, send a message.

## Limits

- Show Claude context still depends on the statusline being installed: Claude Code gives the numbers to nobody else. A user who has their own status line (never replaced) gets no context data.
- The avatar is 16 rows tall; use a taller terminal or `make statusline-logo ROWS=12` and rebuild if it is too big as a lone line.
- Not exercised in a real Claude Code session.
