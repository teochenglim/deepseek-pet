# RELEASE v0.8.5: Homebrew install works

**Status:** active
**Exit gate:** `brew tap teochenglim/deepseek-pet https://github.com/teochenglim/deepseek-pet && brew install --cask teochenglim/deepseek-pet/deepseek-pet` installs the app
**Depends on:** v0.8.4
**Requirements:** R-D1

Packaging fix: no AC change, no behaviour change.

## What failed

`brew install --cask teochenglim/deepseek-pet/deepseek-pet` made Homebrew clone `github.com/teochenglim/homebrew-deepseek-pet`, a repo that was never created (`Repository not found`). The release job that should have pushed the cask there was also off (`vars.HOMEBREW_TAP` unset, no `TAP_TOKEN`).

## Fix

- The main repo is its own tap: `Casks/deepseek-pet.rb` (rendered for v0.8.4 with the real dmg sha256).
- Tapping a repo not named `homebrew-*` needs its URL, so install is two commands (README updated).
- The `homebrew` release job now renders the cask from the released dmg and commits it to `main` with the default `GITHUB_TOKEN`. No second repo, no PAT, no variable gate. Needs main to accept a push from Actions (no branch protection blocking it).
- The cask lags one tag until that job finishes; the template stays in `packaging/homebrew/`.
