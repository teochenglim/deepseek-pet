# RELEASE v0.4.1: CI and supply-chain fixes

**Status:** active
**Exit gate:** `make check` and `make audit` pass locally; `security.yml` and the tag-driven `release.yml` are green on GitHub
**Depends on:** v0.4.0
**Requirements:** R-D1

Patch release: no AC change, no behaviour change in the app.

## What failed on GitHub (v0.2.0 to v0.4.0)

| Run | Cause | Fix |
|---|---|---|
| ci `supply-chain`, every tag | `deepseek-pet` crate had no `license`, so cargo-deny failed with `unlicensed` | `Cargo.toml` now sets `license = "Apache-2.0"`, `description`, `repository` |
| ci `check` and release `build` | `make test` imports Pillow (`tools/test_convert_assets.py`); the macOS runner's Python had none | `ci.yml` removed; `release.yml` no longer runs `make check` (run it locally before `make release`), so the runner needs no Python deps. `tools/requirements.txt` documents Pillow |
| cargo-deny advisories (found while fixing the above) | quick-xml (2 vulnerabilities), tokio (unsound `AsyncFd`), `instant`, `unic-*`, `proc-macro-error` | `cargo update` tokio to 1.54.1; `notify` 7 to 8 (drops `instant`); `src-tauri/deny.toml` skips Linux/Windows targets and lists the remaining tauri-transitive advisories with reasons; `.cargo/audit.toml` mirrors them |

## Scope


- Workflows reduced to two: `security.yml` (Semgrep, Trivy, cargo-deny; daily 06:00 UTC and on push/PR) and `release.yml` (tag `v*` builds the arm64 `.app`/`.dmg`, publishes the GitHub Release, optionally updates the Homebrew tap).
- `ci.yml` and Dependabot removed; the macOS CI job took 10+ minutes per push and duplicated the local `make check`.
- v0.2.0, v0.3.0 and v0.4.0 tags have failed release runs and no published artifacts; v0.4.1 is the first release meant to publish a dmg.

## Built

Verified (2026-11-06): `make check`, `make audit` (cargo-audit exit 0 with two allowed warnings, cargo-deny all four checks ok), workflow YAML parses, actions pinned.
Limits: the new `security.yml` cargo-deny job and the tag release run have not been seen green on GitHub yet; the `homebrew` job still needs the tap repo, `TAP_TOKEN` and `HOMEBREW_TAP=true`. Open Dependabot PRs from before its removal are not closed.
