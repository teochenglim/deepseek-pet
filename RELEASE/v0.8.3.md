# RELEASE v0.8.3: English / Chinese switch, ZCode animates

**Status:** active
**Exit gate:** the menu-bar icon has a language button; ZCode tool calls play varied Work clips while Claude Code is also running
**Depends on:** v0.8.2
**Requirements:** R-K1

## What changed

- **Language button** at the bottom of the menu-bar menu ("语言: 切换到中文" / "Language: switch to English"). It switches the menu-bar menu, the right-click popup, the clip titles and categories (`title_zh` from the catalog) and the speech bubble (the greeting `Hi!` becomes `欢迎！`, and so on). The choice is saved as `language` in `~/.deepseek-pet/settings.json` and survives a restart. Default is English.
- **ZCode stood still**: the 12 s throttle for default clips used one stamp file shared by every agent, but only the active source's clips play. A busy Claude Code session kept refreshing the stamp, so ZCode's `PreToolUse` never got a random Work clip. The stamp is now per source (`.last-default-clip-<source>`) and the gap is 11 s. `PreToolUse` keeps its default state (working) plus a random pool, as in 0.8.2.
- Hook scripts are copied to `~/.deepseek-pet/hooks` by the app: after updating, open the app once (or re-run Install hooks) so ZCode uses the fixed `common.py`.
