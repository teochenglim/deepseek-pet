- Can GitHub display them? Yes. GitHub renders animated and transparent GIFs inline in a README through a plain `<img>`. APNG and WebP also work, WebM and MP4 do not inline from a repo file. Limits: 1-bit alpha gives slightly hard edges on a dark theme (checked on a dark background, clean), keep each GIF well under 10 MB (these are 70-275 KB).
- The GIFs are regenerated from the frames, never edited by hand (script below).

## Regenerating a GIF

For each `frames/extras/<clip>/NN.png`: resize with Lanczos, quantize to 255 colours with no dithering, paste index 255 over pixels with alpha < 128, save with `transparency=255`, `disposal=2`, `duration=125`, `loop=0` (Pillow). The clip ids used are listed in the README alt text; titles are in `assets/big-blue-fish/frames/extras/catalog.json`.
