# RELEASE v0.8.6: Homebrew cask without deprecation warnings

**Status:** active
**Exit gate:** `brew install --cask teochenglim/deepseek-pet/deepseek-pet` prints no deprecation warning
**Depends on:** v0.8.5
**Requirements:** R-D1

Packaging fix: no AC change, no behaviour change. The v0.8.5 install itself worked; Homebrew 7 only warned.

## What warned

| Warning | Cask line | Fix |
|---|---|---|
| `depends_on macos:` string comparison is deprecated | `depends_on macos: ">= :ventura"` | `depends_on macos: :ventura` |
| `postflight` is deprecated | `postflight do system_command "/usr/bin/xattr" ... end` | `postflight_steps do run "/usr/bin/xattr", args: [...], writable_paths: [...] end`, app path written as `{{appdir}}/DeepseekPet.app` (the steps DSL takes template tokens, not Ruby interpolation) |

Changed in both `Casks/deepseek-pet.rb` and the template `packaging/homebrew/deepseek-pet.rb`, so the release job keeps rendering the fixed form. `must_succeed: false` keeps a missing quarantine attribute from failing the install.
