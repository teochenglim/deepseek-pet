## Built

Verified (2026-11-06, macOS arm64):
- `make check` green (fmt, clippy, prettier/eslint, ac-map, 10 AC tests, upstream Rust/Python/Node tests).
- `make build` produced `DeepseekPet.app` and `DeepseekPet_0.1.0_aarch64.dmg` (A0.1.1).
- Release binary started, loaded 57 frames from `assets/big-blue-fish/frames`, listened on `/tmp/kotori-pet.sock`; piping a `Stop` payload into `pet-hook.sh claude-code` produced `aggregator: state=jumping active=1` in the app log (A0.1.5, backend side).
- Idle frames 00-05 are the Big Blue Fish still (alpha decoded with libvpx-vp9, cropped, 192x208).
- Idle RSS about 116 MB right after launch (0.1.0 has no budget; 1.0.0 target is 80 MB).

Limits (needs a human on macOS): transparent background and no shadow rectangle (A0.1.2), stays above Finder/browser (A0.1.3), not in Dock/Cmd+Tab, fish drawn correctly in the window. Screen capture was not permitted in this session. Real Claude Code `~/.claude/settings.json` Stop hook not exercised. dmg not installed or opened. Icons were upstream placeholders; replaced in the 0.3.0 work (see below).

Deviations from the PRD: hook command is `pet-hook.sh claude-code` with JSON on stdin; macOS endpoint is the Unix socket; layout stays `desktop/cross-platform/` because config.rs and the hook scripts hard-code it; frames live in `assets/big-blue-fish/frames`; all six idle frames use the same still; other states are placeholder Kotori frames.
