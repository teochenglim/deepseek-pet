# RELEASE v0.3.0: Claude Code + Z.ai Dual-Hook Integration

**Status:** active
**Exit gate:** Events from both agents switch the fish state
**Depends on:** v0.2.0
**Requirements:** R-H1, R-H2, R-S1

## Scope

- Hook mapping lives in `config.example.json` `state_map`: PreToolUse/UserPromptSubmit/PostToolUse -> running, Stop -> jumping (celebration, then the backend clears it to idle), StopFailure and PostToolUseFailure -> failed, PermissionRequest -> waiting. `StopFailure` is no longer a terminal event, otherwise the session was deleted and `failed` never showed. Only `SessionEnd` ends a session. Bubble text is now English.
- Z.ai: ZCode has real command hooks (`~/.zcode/cli/config.json`, `hooks.enabled` + `hooks.events.<Event>`, docs at zcode.z.ai/en/docs/hooks). Its stdin JSON matches Claude Code's, so no bridge script is needed: `pet-hook.sh zai` (new case, `zai_hook.py`) only sets `source: zai`. Events: SessionStart, UserPromptSubmit, PreToolUse, PermissionRequest, PostToolUse, PostToolUseFailure, Stop. Project-level ZCode hooks are not executed by ZCode, so only the user config is used.
- `scripts/install-hooks.sh` / `scripts/uninstall-hooks.sh` (-> `tools/install_hooks.py`): idempotent, entries marked `# deepseek-pet`, foreign hooks untouched, one-time `.deepseek-pet.bak`, refuses to overwrite invalid JSON, skips ZCode if `~/.zcode` is absent.
- App icon: Big Blue Fish head on a soft blue rounded square, source `assets/branding/icon-1024.png` (cropped from the idle clip), full set generated with `npx tauri icon` (icns for the .app/.dmg and Dock, ico, png) and listed in `bundle.icon`. Android/iOS output deleted.
- Multi-session aggregation is the upstream backend (`waiting > running > running-left/right > review > jumping > waving > idle > failed`); only tests were added.
