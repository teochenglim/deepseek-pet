# RELEASE v0.4.0: Interaction and State Priority

**Status:** active
**Exit gate:** Drag, click, hover, menu and priority behave per spec
**Depends on:** v0.3.0
**Requirements:** R-I1, R-S1

## Scope

- Drag, hover and one-shot logic are upstream's (`animator.js` `handleDrag`, `triggerHoverJump`, `triggerOneShot`); new here: a single click plays `waving` and returns to the previous state, and the right-click menu gets `Hide for now` next to `Quit`.
- Hide calls `hide_pet`; a new menu-bar icon (`Show Big Blue Fish` / `Quit`) brings the pet back. Quit and the tray share `commands::shutdown`, which removes the socket before `app.exit(0)`.
- All nine animation states now use Big Blue Fish clips (`tools/state-map.json`): running-left and a mirrored running-right come from `原地左转奔跑`, waiting from `工作状态-原地踱步张望`, review from `工作状态-思考冒泡`, waving from `点击回应-元气挥手`, jumping from `点击回应-开心跃动`. No pixel-art placeholders remain.
- Triple click still purges sessions (upstream); the first two clicks of a triple click each play a wave.
- Animation behaviour tests run the real `SpriteAnimator` under Node (`hooks/tests/animator-interaction.test.mjs`); the Rust AC tests call them by name, so `node` is needed for `cargo test`.

## Built

Verified (2026-11-06, macOS arm64):
- `make check` green: 17 ACs, 2+ tests each; 5 Node tests drive the real `SpriteAnimator` (drag returns to `running`, click wave returns to `running` and follows a mid-wave `waiting`, hover jump only when idle); 3 aggregator priority tests; socket cleanup test.
- Rebuilt app starts with the new menu-bar icon code and loads 72 frames (9 states x 8). Claude + ZCode events: running, then waiting, then running, in the expected priority order. `.dmg` 5.8 MB, idle RSS about 113 MB.
- Dependabot removed; `security.yml` now runs daily.

Limits (needs a human): the context menu items, Hide, restoring from the menu-bar icon and Quit were not clicked; the menu-bar icon appearance; dragging, click wave and hover jump were verified in the state machine, not on screen; how the new clips look and loop; the mirrored right-run direction. Quit via menu removes the socket in code and in a unit test, but a SIGTERM kill leaves a stale `/tmp/kotori-pet.sock` (the startup probe reclaims it).
