# RELEASE v0.9.0: Claude Code statusline with the avatar, and Show context

**Status:** active
**Exit gate:** the status line prints the avatar and context numbers, Show context is on the menu-bar icon and the right-click menu, and `make check` is green
**Depends on:** v0.8.12
**Requirements:** R-X1

## What

- **Status line.** `deepseek-pet --statusline` (answered in `main.rs` before Tauri starts) reads Claude Code's status line JSON from stdin, prints the pet's avatar (half-block colour text, 6 rows, `hooks/statusline-logo.ansi`) beside model, folder, context bar and cost, and saves the numbers to `~/.deepseek-pet/context.json`. Written in Rust on purpose: a Mac without Python (or jq, Node, chafa, ffmpeg) still works.
- **Install.** Menu-bar icon, Install hooks, Claude Code statusline. It sets `statusLine` in `~/.claude/settings.json` to `~/.deepseek-pet/bin/statusline --statusline # deepseek-pet`, a symlink to the app that is refreshed at launch so an upgrade or move keeps working. Key order is kept, a one-time `settings.json.deepseek-pet.bak` is written, a status line the user already has is never replaced, and a settings file that is not JSON is never overwritten.
- **Show context.** New entry on the menu-bar menu and the right-click menu; shows model, window use bar, tokens, cache read/write, cost and age in the speech bubble for 15 s.
- Avatar regenerated with `python3 tools/make_statusline_logo.py` (Pillow, development only).

## Dependencies

No new crate. `serde_json` gets the `preserve_order` feature so the user's `settings.json` keeps its key order (`indexmap` was already in the tree).

## Limits

- `/context` output is not reachable by other programs; Show context uses the status line's numbers, so it is empty until the statusline is installed and one turn has run. It is not the category breakdown `/context` draws.
- Not exercised: a real Claude Code session, the bubble layout at the real window size, and the symlink path from an installed `.app`. Needs a manual pass (install from the menu, restart Claude Code, run a turn, click Show context).
- The status line starts the app binary for every refresh (it exits before any window code, a few tens of ms).
